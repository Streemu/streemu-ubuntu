# Streemu para Linux

O Streemu para Linux está em preparação. É o mesmo app do [Streemu de PC](https://github.com/Streemu/Streemu), feito para o Ubuntu, que conversa com quem usa Windows.

A primeira versão vai enviar e receber arquivos na sala do grupo. Assistir às lives e transmitir vêm depois.

Este repositório vai receber o código que roda no seu computador, para conferir e compilar do zero, e a página de versões vai trazer o app pronto para baixar. O servidor do grupo **não** fica aqui.

Ainda não há versão para baixar.
